# SNU Library Inspired — 3D 실시간 스터디룸 v2

**서울대학교 중앙도서관 내부 사진에서 영감을 받은 비공식 웹 3D 공간**입니다. 서울대학교 공식 서비스나 디지털 트윈이 아닙니다.

v1에서 구현한 Three.js 기반의 도서관, 88개 책상/352개 의자, 카메라 제어, 로우폴리 동물 아바타, 로컬 NPC 8명, A* 이동, 착석, 공부시간, 닉네임/채팅 말풍선을 유지하고 **실제 Node.js + WebSocket 서버**를 추가했습니다. NPC는 실제 이용자로 표시하거나 집계하지 않습니다.

## 준비물

- **Node.js 22 이상** (Node.js 22 이상 권장)
- PC 및 스마트폰 브라우저 (최신 Chrome, Edge, Safari 권장)
- **인터넷 연결**: Three.js 0.161.0 및 OrbitControls를 `cdn.jsdelivr.net`에서 가져옵니다. 서버 자체에는 NPM 패키지 설치가 필요하지 않습니다.
- 브라우저에서 직접 `file://index.html`로 여는 것은 지원하지 않습니다. 반드시 아래 서버 주소로 접속하세요.

## 서버 실행

압축을 해제한 프로젝트 최상위 폴더에서 다음 명령을 실행하세요.

```sh
node server/index.js
```

또는 Windows는 `start_server.bat`, macOS/Linux는 `./start_server.sh`입니다. `npm start`도 됩니다. **`npm install`은 필요 없습니다.** 기본적으로 `0.0.0.0:3000`에 HTTP 서버와 WebSocket 서버가 함께 열립니다.

PC 브라우저 주소:

```text
http://localhost:3000/?room=main
```

서버 콘솔 창을 닫으면 다른 사용자와의 연결도 종료됩니다. 테스트할 때는 창을 열어 두세요.

포트 변경 (macOS/Linux):

```sh
PORT=3100 node server/index.js
```

Windows PowerShell:

```powershell
$env:PORT=3100; node server/index.js
```

## PC + 스마트폰 동시 접속 테스트

1. **PC와 스마트폰을 같은 Wi-Fi**에 연결합니다. PC에서는 `http://localhost:3000/?room=main`에 접속합니다.
2. PC의 **사설 IPv4 주소**를 확인합니다. Windows `ipconfig`의 IPv4 주소, macOS `ipconfig getifaddr en0` 등을 사용합니다.
3. 스마트폰에서는 `http://PC의_IP주소:3000/?room=main`에 접속합니다. 예를 들어 `http://192.168.0.15:3000/?room=main`입니다. IP 주소는 실제 사용 중인 PC 주소로 바꾸세요.
4. 각 기기에서 **서로 다른 닉네임과 후드 색**을 지정합니다. 각 기기는 서버 발급 게스트 토큰이 별도로 저장되어 독립 사용자로 접속합니다.
5. 상단에 **실제 접속자 2명 · NPC 8명**이 표시되는지 확인합니다. NPC는 머리 위 `NPC ·` 표시로 구분됩니다.
6. PC에서 중앙 통로 바닥을 클릭해 이동시키고 스마트폰에서 해당 캐릭터가 이동하는지 봅니다. 스마트폰에서 바닥을 탭해 반대 방향으로 이동시켜 확인합니다.
7. PC에서 빈 의자를 누른 뒤 도착·착석까지 확인합니다. 같은 의자를 스마트폰에서 누르면 서버가 중복 예약/착석을 거절해야 합니다.
8. PC에서 짧은 채팅을 입력하면 두 기기에서 해당 캐릭터 머리 위에 5초 말풍선이 표시되는지 확인합니다.
9. 스마트폰에서 **초대 링크**를 복사해 다른 사람에게 전달할 수 있습니다. 링크의 `?room=...` 값이 같으면 같은 방입니다. LAN 테스트에서는 `localhost`가 아닌, 친구가 접속 가능한 서버 IP 또는 도메인이 링크에 있어야 합니다.
10. 착석 상태에서 스마트폰 Wi-Fi를 잠시 껐다가 **20초 안에 복구**하면 동일한 게스트 토큰으로 좌석이 복구됩니다. 오프라인 동안 공부 타이머는 일시정지됩니다. 20초 유예 시간이 지나면 서버가 좌석을 회수합니다 (최대 약 1초 정도의 정리 오차).

한 컴퓨터에서 2명을 시험하려면 **일반 창과 시크릿 창**을 사용하세요. 같은 브라우저 프로필의 일반 탭 2개는 토큰을 공유하므로 두 번째 연결이 첫 번째 연결을 교체합니다.

스마트폰에서 접속되지 않으면 PC 방화벽의 **TCP 3000** 포트를 확인하고, 게스트 Wi-Fi의 **기기 간 통신 차단(AP isolation)** 여부를 확인하세요. 휴대폰 모바일 데이터망에서는 PC의 사설 IP에 직접 접속할 수 없습니다.

## 기본 조작

- PC: 마우스 드래그로 카메라 회전, 휠로 확대/축소, 바닥 클릭 이동, 의자 클릭 착석, WASD/방향키 이동, Shift 빠르게
- 스마트폰: 한 손가락 드래그로 카메라 회전, 짧은 탭으로 이동/의자 선택, 두 손가락 핀치로 확대/축소
- 상단: 카메라 따라가기, 캐릭터 편집, 방 초대 링크 복사, 도움말
- 하단: 공부 시간 확인, 타이머 일시정지/재개, 좌석에서 일어나기, 40자 이내 채팅


## 서버의 권한 및 동기화 기준

- 서버가 HMAC 서명한 **게스트 토큰**으로 동일 사용자를 식별합니다. 임의의 사용자 ID, 좌석 점유, NPC 역할은 클라이언트가 지정할 수 없습니다.
- 방 이름은 `a-z`, `0-9`, `_`, `-`만 허용하며 최대 32자입니다. 방당 동시 접속 인원은 최대 64명입니다. 다른 방에서는 위치/채팅을 공유하지 않습니다.
- 서버는 v1과 동일한 순서로 좌석 번호와 이동 장애물을 생성합니다. **8개 NPC의 기본 좌석을 실제 사용자에게 할당하지 않습니다.**
- 좌석은 서버에서 예약(최대 90초) 후, 유효한 예약자가 실제 접근한 위치를 확인했을 때 착석이 확정됩니다. 서버는 예약 및 착석 중복 점유를 거절합니다.
- 클라이언트는 약 10Hz로 자기 위치를 전송합니다. 서버는 이동 속도, 이동 구간의 장애물 통과와 공간 범위를 검증하고 다른 참가자에게 전달합니다. 다른 사용자의 위치는 클라이언트에서 보간합니다. **물리 엔진 수준의 완전한 안티치트는 아닙니다.**
- 공부 시간은 서버 메모리에서 계산하고 약 1초마다 공유합니다. 착석하면 공부 시간 증가, 일시정지/재개, 기립 및 연결 끊김 시 정지를 지원합니다.
- 인터넷이 잠시 끊겼다면 해당 좌석과 게스트 상태를 **20초** 유지하고, 동일한 토큰으로 재접속하면 복구합니다. 20초 이후에는 좌석 점유를 해제하고 다른 사용자에게 퇴장을 전송합니다.
- 테스트용 NPC의 스트레칭/산책 행동은 계속 브라우저 **로컬 시뮬레이션**입니다. NPC 행동을 서버에서 동기화하지는 않습니다.

## 테스트

프로젝트 폴더에서 다음 명령을 실행합니다.

```sh
npm run check
npm test
```

`npm test`는 Node.js의 **실제 WebSocket 클라이언트 3개**를 서버에 연결하고 게스트 인증, 방 격리, 실시간 채팅, 이동 검증, 좌석 예약 경합, NPC 전용 좌석 거부, 의자 접근 후 착석, 시간 일시정지, 재접속 좌석 복구 및 유예 시간 후 점유 해제를 자동 확인합니다.

**테스트 범위와 한계:** Node 통합 테스트는 수행할 수 있지만, 이 프로젝트에 포함된 외부 Three.js CDN을 실제 스마트폰과 PC에서 로드한 뒤 그래픽 품질, 터치 제스처 및 WebGL 프레임 성능까지 자동 검증하는 테스트는 포함되지 않습니다. 반드시 실제 기기에서 위 절차를 추가 확인하세요.

## 운영 배포 전 확인사항

- 초기 버전은 **DB 없는 단일 Node.js 프로세스의 메모리 저장**입니다. 서버를 재시작하면 좌석, 모든 방 상태, 서버 공부 기록이 초기화됩니다. 기본 게스트 토큰 서명 키는 `.guest-secret`에 생성·유지됩니다. 파일은 외부에 공유하지 마세요. 기존 v1의 `localStorage` 공부시간은 서버 기록으로 가져오지 않으며, 1단계 저장값은 프로필 선호도로만 재사용합니다.
- 공부 기록을 영구 저장하거나 여러 서버 인스턴스로 확장하려면 데이터베이스, 계정 인증, 공유 저장소/메시지 브로커, 서버 간 룸 동기화가 필요합니다.
- 공개 배포에는 **HTTPS/WSS**, 리버스 프록시, 접속·요청 속도 제한, 로그/모니터링, 도메인·권한 정책, 적절한 개인정보 정책이 필요합니다. 현재 예제는 개인 개발·같은 Wi-Fi 테스트용이며 인터넷에 보안 설정 없이 노출하지 마세요.
- 현재 초대 링크는 **방 주소 공유**이며 비공개 입장 비밀번호/접근 권한이 아닙니다.
- 채팅은 메시지를 저장하지 않습니다. 브라우저 새로고침 후 기존 채팅 기록은 복구되지 않습니다.
- 정확한 건물 실측 자료나 CAD 없이 사진을 참고해 절차적으로 구성한 공간이며, 공식 서울대학교 서비스가 아닙니다.
