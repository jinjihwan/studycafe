# V7.9 — 테스트 결과

## 범위
- 도서관 변경창에서 학교별 학습자 수/좌석 수 표시 (`38명/48석`)
- 추가 방 활성화 시 48석 단위 좌석 수 확장 (`…/96석`, `…/144석`)
- 계정/Google 로그인 팝업의 가상 학습자 안내 문구 제거
- 서울대 A형(ㅅ자) 기둥 4개의 바닥 기준 경사를 약 45°로 변경하고 서버 발 위치 충돌 영역 동기화
- 캐릭터 설정창 X / Escape 닫기 및 변경 내용 취소

## 테스트
- `FORCE_COLOR=0 npm run check`: 통과
- `FORCE_COLOR=0 npm test`: 총 145개 / 통과 144개 / 실패 0개 / 건너뜀 1개 (별도 PostgreSQL 실환경 설정 필요)
- 로컬 HTTP `/api/rooms/status` GET 200 확인. 예시 응답: 서울대 학습자 5, 좌석 48; 고려대 학습자 5, 좌석 48; 연세대 학습자 5, 좌석 48. 시간이 달라지면 수치도 달라짐
- 320, 360, 390, 430, 768, 1280 px 정적 브라우저 레이아웃 확인: 카드의 가로 넘침 없음, X 버튼 정상 배치
- 새로운 좌석 총합 계산 유닛 테스트: 48/96/144석에 맞춰 합산, 타 학교 사용자는 제외
- 서울대 기둥 45도 기하 검증 및 서버 이동 장애물 8개 발 위치 일치 검사 통과

## 주의
- 테스트 환경에서 3D CDN 외부 접속을 통한 실제 Three.js 렌더링과 Railway 실환경 PostgreSQL 다중 워커 통합은 수행하지 못했습니다. 배포 후 스마트폰에서 기둥/카메라/도서관 간 전환을 확인하세요.
- 도서관 선택창의 분자는 해당 대학 전체 방에 접속 중인 실제 이용자와 그 시각 첫 번째 방에서 활동 예정인 가상 학습자 합계입니다. 분모는 첫 번째 방 48석과 현재 사람이 접속해 있는 추가 방 48석씩을 더한 물리적 좌석 수입니다. 실제 착석한 사람만 세는 지표는 아닙니다.
- 실제 운영 사용자의 DB 기록·좌석·랭킹에는 수정이 없습니다.
