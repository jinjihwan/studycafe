# V7.10 - 같은 방 실시간 채팅 표시 보완

- 기존 V7.9 UI와 서버 WebSocket의 방별 채팅 전달 로직은 그대로 유지합니다.
- 이전에는 캐릭터 머리 위 말풍선이 거리에 따라 숨겨져, 수신한 채팅이 전혀 보이지 않을 수 있었습니다.
- 새 버전에서는 같은 방의 모든 채팅 메시지가 도착하면 하단 채팅 입력창 위에 짧게 표시됩니다.
- 최대 3개 메시지를 12초 동안 보여주며, 새 채팅이 없으면 표시 영역이 비어 공간을 차지하지 않습니다.
- 채팅 문자열은 `textContent`로 안전하게 삽입합니다. 최대 40자, 닉네임 최대 15자를 유지합니다.
- 가까이 있는 사용자의 3D 머리 위 말풍선은 이전과 동일하게 유지합니다.
- **채팅은 같은 방에서만 공유됩니다.** 같은 대학이라도 1번 방과 2번 방이 다르면 메시지가 전달되지 않습니다.

## 적용 대상
- `index.html` (프런트엔드 표시만)
- `tests/v710-chat-visibility.test.js` (신규 테스트)
- `package.json`, `package-lock.json` (버전)

기존 NPC, 좌석, 공부 기록, Google 로그인, 방 자동 확장, 관리자의 인원 현황 등은 변경하지 않습니다.
