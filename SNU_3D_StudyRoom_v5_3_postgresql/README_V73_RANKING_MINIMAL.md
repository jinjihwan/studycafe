# V7.3 · 랭킹 간소화 및 튜토리얼 제거

V7.2 기반의 소규모 화면 패치입니다.

## 변경 사항

- 오늘의 전체 랭킹에서 순위, 닉네임, 공부 시간만 노출합니다.
- 동물 종류, 후드 색상, HEX 코드(#aaa4dc 등), 랭킹 이모지 아바타를 노출하지 않습니다.
- 첫 방문자용 8단계 튜토리얼 CSS, 오버레이, 조작 감지 및 자동 시작 로직을 제거합니다.
- 기존 첫 방문 캐릭터 선택(닉네임/동물/후드) 창은 그대로 유지합니다.
- NPC 144명 명단, 개별 공부 리듬, 랭킹 1초 기준, 좌석/서버 프로토콜/로그인/채팅은 변경하지 않습니다.
- 기존에 사용자가 저장한 튜토리얼 관련 브라우저 데이터는 읽거나 사용하지 않습니다.
