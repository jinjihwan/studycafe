# 코루라이브 3D 스터디카페 — V6.5 UI 정리 및 걷기 애니메이션

기반: `studycafe-main.zip`의 V6.4 통합 프로젝트. 이 배포본은 패치가 아닌 **전체 소스코드**를 포함합니다.

## 적용된 8가지 요구 사항

1. 카메라 추적을 항상 활성화하고 토글 버튼 제거.
2. 키보드·마우스·터치 조작 설명 UI 및 도움말 버튼 제거. 입력 로직 유지.
3. 기존 동물 아바타의 후드·털·손발 메시를 유지하고 어깨/엉덩이 피벗을 만들어 교차 보행 동작 추가. 실제 프레임 이동량으로 속도/진폭 계산하며 정지하면 중립 자세로 복귀. 로컬 사용자·원격 사용자·NPC를 동일 애니메이션 패스에서 갱신.
4. 이동 중 메시지 및 별도 상태 표시 영역 제거. 내부 상태 처리 및 토스트 오류 알림은 유지.
5. 하단 별도 공부 시간 제거. 머리 위 타이머, 서버 공부 시간 및 통계/랭킹 유지.
6. 일시정지·자리에서 일어나기 UI 버튼만 제거. 서버 좌석 이동/반납과 기존 일시정지 프로토콜 구현은 유지.
7. 사용자에게 표시되던 `비공식 3D` 등 불필요한 설명 문구 제거.
8. 도서관 변경에서 인테리어 설명 제거. 도서관 명칭과 48석 정보만 표시.

## 수정 파일

- `index.html`: 8개 UI 변경, 기존 동물 모델의 걷기 피벗, 원격/NPC 보행 호출, 시각적 카메라 추적 유지.
- `client/walk-animation.js` (**신규**): 이동 속도 기반 보행 상태 계산. 프레임당 새 객체를 만들지 않음.
- `server/index.js`: 신규 클라이언트 JS 파일을 브라우저에 제공하기 위한 정적 파일 허용 목록 추가. API/좌석/채팅/랭킹 로직은 변경하지 않음.
- `package.json`, `package-lock.json`: 버전 `6.5.0-ui-walk.1` 표기.
- `tests/v65-ui-walk.test.js` (**신규**): UI 제거 범위, 기존 이벤트/타이머 보존, 보행 상태 동작 및 네트워크 연동 코드 회귀 검사.
- `.env.example`: 기존 전체 ZIP에서 비밀키 없는 예제 환경 변수 템플릿 복구. `scripts/check-project.js` 요구 파일임.
- `README_V65_UI_WALK.md`, `TEST_REPORT_V65_UI_WALK.md`: 수정 및 검증 문서.

## 로컬 실행과 검증

Node.js 22.13 이상이 필요합니다.

```bash
npm ci
npm run check
npm test
npm start
```

기존 사용자 DB, Railway 환경 변수, Firebase 인증 설정, 비밀키는 덮어쓰지 마세요. 배포할 때는 GitHub의 실행 프로젝트 디렉터리(기존 `index.html`, `server/`, `client/`, `package.json`이 함께 있는 폴더)를 이번 전체 소스로 업데이트하고 기존 Railway 빌드/시작 명령을 유지하세요. 실제 운영 인스턴스에는 이 파일 작성 시점에 배포하지 않았습니다.

## 검증 범위와 한계

- `npm run check`: 통과. 정적 HTML 모듈 구문, 서버/클라이언트 Node 구문, 프로젝트 파일 구성 확인.
- `npm test`: 90개 중 89개 통과, 1개 건너뜀(별도 테스트용 PostgreSQL 연결 정보 없음), 실패 0개.
- 로컬 Node 서버에서 `/`, `/client/walk-animation.js`, `/client/network.js`: HTTP 200 확인.
- Chromium의 PC 1280×800, 모바일 390×844, 소형 모바일 320×640 DOM/CSS 검사: 제거 대상 UI 없음, 채팅 영역 정상 배치, 가로 스크롤 없음.
- 보행 수학과 서버 프로토콜 회귀는 자동 검증했지만, 외부 Three.js CDN을 로드하는 **실제 3D 렌더링 및 Railway 운영 환경에서의 사용자 동작은 테스트하지 못했습니다.** 배포 전 실기기 2대 이상으로 시각적 보행/멀티플레이어를 확인해야 합니다.
- 별도의 번들링/빌드 스크립트가 없는 **정적 HTML + Node 서버** 프로젝트여서 `npm run check`를 구문/자산 검사에 사용했습니다.
