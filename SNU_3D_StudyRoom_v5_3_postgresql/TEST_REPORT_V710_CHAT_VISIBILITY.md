# V7.10 - Chat Visibility Test Report

## 수정 내용
- 같은 방에서 수신한 모든 채팅을 거리/캐릭터 라벨 표시 제한과 독립적으로 화면에 출력
- 하단 입력창 위에 최대 3건 표시; 각 메시지는 수신 후 12초 뒤 자동 제거
- 닉네임 / 메시지는 `textContent`로 삽입하여 HTML 실행을 막음
- 기존 머리 위 말풍선, 서버의 방별 채팅 방송, 로그인·좌석·NPC 등 유지

## 검사 결과
- `npm run check`: 통과
- `FORCE_COLOR=0 npm test`: 총 148개 중 **147개 통과**, 실패 0개, 건너뜀 1개
  - PostgreSQL 실환경 전용 테스트는 별도 테스트용 DB 연결 정보가 없어 건너뜀
- 새 전용 테스트 3개: 전부 통과
  - 수신 채팅이 거리 제한과 관계없이 표시되는 구조
  - 본문 HTML 이스케이프, 최대 3개, 12초 만료
  - 기존 서버 WebSocket 같은 방 방송 유지
- 모바일 320/360/390/430px, 태블릿 768px 및 PC 1280px 정적 브라우저 레이아웃:
  - 입력창과 피드 겹침 없음
  - 하단 네비게이션과 겹침 없음
  - 가로 스크롤 없음

## 제약
- 실제 운영 Railway/Cloudflare에서 두 대의 스마트폰으로 동시에 접속한 엔드투엔드 테스트는 아직 하지 못했습니다.
- 다른 **방**의 채팅은 표시되지 않는 기존 방별 분리가 유지됩니다.
