# V7.11 – 캐릭터 머리 위 채팅 말풍선

## 변경 사항

- V7.10의 하단 채팅 기록 오버레이를 완전히 제거했습니다.
- 같은 방의 실제 사용자 채팅은 **말한 캐릭터 머리 위** 말풍선으로 표시합니다.
- 말풍선 내부 순서: 채팅 메시지 → 닉네임 → 공부 시간. 채팅만 닉네임/시간 카드의 위에 붙어서 표시됩니다.
- 내 캐릭터 또는 내 위치에서 약 10.56 월드 단위 내의 캐릭터만 채팅이 보입니다. 멀리 있는 사람의 채팅은 표시하지 않습니다.
- 카메라와의 거리로 계산한 이름표 등급이 멀더라도 실제 사용자끼리 가까우면 채팅 말풍선이 보이게 했습니다.
- NPC가 많아 말풍선의 표시 제한에 걸릴 때 가까운 곳에서 채팅 중인 사람을 우선 표시합니다.
- 메시지는 전송된 뒤 5초 동안 보여 주고 캐릭터 위치를 따라 움직입니다.
- 기존 40자 제한, 방별 서버 채팅 분리, 닉네임·공부 시간, NPC·좌석·랭킹·로그인은 변경하지 않았습니다.
