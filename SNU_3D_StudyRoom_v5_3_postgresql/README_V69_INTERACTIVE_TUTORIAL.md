# 코루라이브 V6.9 — 행동 완료형 첫 방문 튜토리얼

## 변경 목적
V6.8의 단순 설명형 8단계 안내를 실제 사용자가 기능을 직접 조작해야 자동으로 넘어가는 튜토리얼로 변경했습니다. 기존 서버 API, 데이터베이스, 3D 모델 및 WebSocket 프로토콜은 변경하지 않았습니다.

## 8단계 완료 조건
1. 화면 이동/확대 축소: 캔버스를 직접 드래그(24px 이상)한 뒤 두 손가락 집기 확대·축소(두 손가락 사이 거리 16px 이상 변화) 또는 마우스 휠 조작
2. 도서관 변경: 도서관 변경 버튼을 누르고 다른 도서관을 선택해 실제 페이지가 전환됨. `sessionStorage`로 단계 상태를 잠시 보관하여 새 도서관에서 3단계를 이어감
3. 캐릭터 변경: 캐릭터 선택창에서 닉네임·동물·성별 기본색·후드 색상 중 하나 이상 실제 변경 후 저장
4. 바닥 터치 이동: 바닥을 터치한 뒤 경로 이동 완료 콜백 실행
5. 의자 착석 및 공부 시작: 유효한 좌석 요청 후 서버가 착석 상태와 공부 시간 시작을 확인
6. 말하기: 기존 실시간 채팅 전송 함수가 메시지 전송을 정상 요청함
7. 친구 초대: 초대 링크 복사가 성공하거나 공유 링크 안내가 확인됨
8. Google 로그인 안내: 계정 버튼을 직접 눌러 Google 로그인 화면을 열면 완료. 로그인 자체는 강제하지 않음

단계별 '이 단계 건너뛰기'와 전체 '튜토리얼 종료' 제공. 단계가 종료되면 브라우저 로컬 저장소에 완료 표시. 기존 V6.8 튜토리얼을 마친 이용자에게는 자동으로 다시 나타나지 않습니다.

## 테스트 재진입
- 기존 이용자는 주소에 `?room=korea&tutorial=1`처럼 `tutorial=1` 쿼리를 넣으면 다시 체험할 수 있습니다.
- 시작 시 `tutorial` 쿼리는 주소에서 제거되므로 초대 링크 등에 붙지 않습니다.
- 완전히 신규 방문자는 첫 캐릭터 설정과 도서관 선택이 끝난 뒤 튜토리얼이 나타납니다.

## 정확한 공부 시간 안내
현재 서버는 **WebSocket 연결이 끊기면** 공부 기록을 일시정지합니다. 단순히 다른 앱으로 전환해 브라우저가 백그라운드에 있어도 연결이 유지되면 기록은 계속될 수 있습니다. 이번 UI 패치는 해당 공부 시간 정책을 임의로 변경하지 않았습니다.
