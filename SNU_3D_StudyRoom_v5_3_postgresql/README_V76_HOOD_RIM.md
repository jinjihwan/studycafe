# V7.6 후드 테두리 공중 분리 수정

## 증상

토끼 등 캐릭터의 후드 앞 원형 테두리가 얼굴로부터 앞으로 떨어져 보임. 회전 및 이동 시 테두리는 이미 캐릭터를 정상적으로 따라감.

## 원인과 수정

- 후드의 둥근 표면 중심: z = -0.085, 반경 z = 0.49.
- 기존 후드 테두리의 중심: z = 0.47. 얼굴 경계의 실제 후드 표면은 약 z = 0.19~0.20으로 그 사이에 간격이 생김.
- 테두리를 z = 0.20으로 뒤로 옮겨 후드 표면과 맞물리게 조정.
- 후드 및 머리의 부모 계층, 몸 움직임/회전, 캐릭터 외형 옵션, NPC, 서버, 랭킹, 좌석 기능은 모두 유지.

## 검사

`npm run check`

`FORCE_COLOR=0 npm test`

회귀 테스트에 후드 테두리와 구형 후드 곡면의 좌표를 비교하는 기하 검사를 추가.
