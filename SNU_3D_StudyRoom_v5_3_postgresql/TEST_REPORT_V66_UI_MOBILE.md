## 브라우저 레이아웃 검사

Chromium에서 로컬 HTML/CSS를 직접 로딩하고, 내비게이션을 보이게 한 상태로 검사. 인터넷/로컬 웹 접근이 제한되어 전체 Three.js 3D 실행 및 실제 멀티플레이어 연결은 테스트하지 못함.

| 화면 폭 | 검사한 HTML 가로 넘침 | 상단/하단 버튼 화면 밖 | 채팅/내비게이션 겹침 |
| ---: | --- | --- | --- |
| 320px | 없음 | 없음 | 없음 |
| 360px | 없음 | 없음 | 없음 |
| 390px | 없음 | 없음 | 없음 |
| 430px | 없음 | 없음 | 없음 |
| 768px | 없음 | 없음 | 해당 없음(PC 네비게이션 상단) |
| 1280px | 없음 | 없음 | 해당 없음(PC 네비게이션 상단) |

**검증 범위 주의:** 브라우저 캡처는 3D CDN 없이 HTML/CSS 영역만 검사한 결과입니다. 실제 모바일 실기기에서 3D 장면, 카메라 구도, 말풍선 가독성, 네트워크, 가상키보드가 정상이라고 주장할 수 없습니다.

## 실제 운영 환경에서 확인해야 할 사항 (미검증)

- 모바일 Android/iOS: 3D 로딩, 상단 실접속자 수, 카메라 프레이밍과 추적, 말풍선 4단계·겹침·표시 한계, NPC/원격 플레이어 동기화.
- 모바일 가상 키보드: 입력창 위치, 포커스, 키보드 닫은 뒤 채팅창 원위치.
- 계정: 게스트/Google 로그인 상태별 아이콘의 접근 가능한 이름과 계정 메뉴 진입.
- 실제 채팅 전송/수신, 좌석 착석·퇴석, 공부시간/일별 기록/랭킹, 친구, 초대 링크.
- Railway 배포 성공 여부, 대량 접속 2,000명 부하 및 모바일 성능/FPS.

배포는 수행하지 않았으며 배포 성공으로 표시하지 않습니다.
