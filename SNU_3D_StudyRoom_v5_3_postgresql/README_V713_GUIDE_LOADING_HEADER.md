# V7.13 온라인스카: 안내 이미지·첫 방문 안내·로딩·상단 크기

## 변경 사항
- `assets/guide.jpg`: 사용자가 제공한 이용 안내 이미지로 완전 교체 (원본은 `.png` 확장자였으나 파일 내용은 JPEG입니다).
- `index.html`: 이용 안내 버튼은 브라우저에서 한 번도 열지 않았을 때만 노란 점과 은은한 펄스로 강조됩니다. 버튼을 누르는 즉시 강조가 해제되고, `localStorage`에 열람 여부가 저장됩니다. 저장 기능이 차단되어도 안내 버튼은 정상 동작합니다.
- `index.html`: 시작 로딩 문구를 `온라인스카 입장하는 중...`으로 변경했습니다.
- `index.html`: 모바일에서 상단 도서관 정보 박스가 남은 가로 공간 전체를 차지하던 CSS를 수정하여 내용 너비만 차지하도록 했습니다. 긴 도서관 이름은 좁은 화면에서 말줄임표 처리합니다.
- 움직임 줄이기 환경설정에서는 안내 버튼 애니메이션을 사용하지 않습니다.

## 배포 및 확인
1. `npm run check`, `npm test` 실행.
2. 모바일 새 브라우저나 시크릿 창에서 안내 `?` 아이콘 주변의 작은 강조가 보이는지 확인.
3. 안내를 한 번 열고 닫은 뒤 새로고침해 강조가 사라진 상태가 유지되는지 확인.
4. 안내 이미지를 열어 올려주신 이미지와 일치하는지 확인.
5. 페이지 진입 시 `온라인스카 입장하는 중...`이 나타나고 도서관 화면이 정상 실행되는지 확인.
6. 서울대/고려대/연세대 도서관의 상단 정보 박스가 내용 너비로 표시되는지 확인.

Railway 환경변수, Firebase, WebSocket, NPC, 좌석, 채팅, 공부 시간, SEO 설정은 변경하지 않았습니다.
