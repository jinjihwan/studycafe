# V7.9 — 도서관 인원·좌석, 서울대 45도 기둥, 캐릭터 선택 닫기

## 화면 변경
- 도서관 변경 팝업에서 각 대학의 학습자 수와 현재 활성화된 방의 전체 좌석 수를 `38명/48석` 형식으로 보여줍니다.
- 1번 방은 48개 물리적 좌석이 있으며, 실제 접속 인원은 최대 32명 + 가상 학습자 최대 16명입니다. 활성화된 추가 방마다 물리적 좌석 48개가 더해져 `…/96석` 등으로 표시됩니다.
- 서버의 `/api/rooms/status`는 기존 실제 접속 인원 필드를 유지하면서 `learners`, `seats` 합계 필드를 제공합니다. 도서관 선택 시 조회하고, 열린 동안 15초마다 갱신합니다. 오류 발생 시 임의의 0명을 표시하지 않습니다.
- Google 로그인/계정 창에서 가상 학습자 안내 문장을 삭제했습니다. 처음 입장하는 캐릭터 설정 안내에서 서비스 내 가상 참여자 정보는 유지합니다.
- 캐릭터 설정 다이얼로그에 X 버튼과 Esc 닫기 기능을 추가했습니다. 최초 방문자는 설정을 저장해야 서버에 접속할 수 있으며, 닫은 뒤 캐릭터 버튼으로 다시 열 수 있습니다.

## 서울대 기둥
- 기존 4개 A형 지지대를 유지하고, 약 76.5°에서 45°(바닥 기준)로 기울어지게 조정했습니다.
- 시각적 발 위치와 서버의 충돌 장애물 위치를 동일하게 수정했습니다.

## 기존 기능 유지
- NPC 144명 일정/공부시간·랭킹, 48좌석의 배치, 이동, 좌석 점유, 채팅, 로그인, 운영자 정보, 안내 이미지 및 자동 방 배정 기능은 변경하지 않았습니다.
