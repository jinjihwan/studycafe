# V7.13 배포 전 검증 결과

## 범위
사용자 제공 새 안내 이미지 교체, 첫 안내 클릭 이전 강조 표시, 시작 로딩 문구 변경, 상단 정보 박스 크기 축소.

## 결과
- `npm run check`: 통과 (HTML 모듈 문법 검사, 프로젝트 자산 검사 포함).
- 관련 테스트 `node --test tests/v713-guide-loading-header.test.js tests/v712-seo.test.js tests/v711-head-chat.test.js tests/v710-chat-visibility.test.js`: 15/15 통과.
- Chromium 오프라인 UI 검증: 320 / 390 / 430 / 1024 px 화면 폭에서 도서관 정보 박스와 버튼이 겹치지 않음. 안내 이미지 1024x1536 표시, 첫 클릭 후 강조 해제, 같은 브라우저 재표시 때 강조 유지 해제 확인.
- 추가 도서관 이름 테스트: 320 / 360 / 390 / 430 / 768 px에서 서울·고려·연세 모두 상단 버튼과 겹치지 않음.
- 전체 `npm test`: 총 160개 중 통과 157, 실패 2, 건너뜀 1. 실패한 기존 `tests/v4-api.test.js`/`tests/v62-yonsei-photo-layout.test.js`의 좌석 획득 테스트는 **변경 전 V7.12 아카이브**에 대해서도 동일하게 실패함을 재현함. 이번 UI 변경으로 유발된 실패는 확인되지 않음.
