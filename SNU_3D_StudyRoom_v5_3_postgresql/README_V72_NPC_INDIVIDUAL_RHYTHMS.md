# V7.2 · NPC 개별 공부 리듬 및 1초 랭킹 기준

V7.1 NPC 144명 일정 모델에서 **NPC마다 똑같은 공부 시간으로 보이는 문제**만 수정했습니다. UI, 3D 도서관 구조, 기존 좌석 정책, 행동형 튜토리얼 및 인증·DB 스키마는 변경하지 않았습니다.

## 변경 사항

- **입장·퇴장 시각**: 15분 배정 구간 안에서 각 NPC의 실제 등장/퇴장 시간을 10~220초 분산시킵니다. 배정 슬롯을 벗어나지 않으므로 최대 동시 16명 상한을 유지합니다.
- **첫 공부 준비 시간**: 입장 후 2~12분으로 개별화합니다.
- **집중 공부 구간**: 매번 40~130분 사이에서 개별화합니다.
- **휴식 구간**: 매번 4~18분 사이에서 개별화합니다.
- **자정 근처 휴식**: 자정을 넘는 긴 방문에는 23:50~00:28 KST 부근에 개별적인 짧은 물·스트레칭 휴식을 배치할 수 있습니다. 이는 실제 시뮬레이션 공부 시간을 멈추는 시간이지, 화면에 보이는 시간만 임의로 보정하는 수치가 아닙니다.
- **결정적 일정**: 학교 + 한국시간 운영 날짜 + NPC 고유 ID로 모든 일정을 계산합니다. 서버 재시작·새로고침 후에도 동일하게 재현됩니다.
- **NPC 랭킹**: 오늘 누적 공부 시간이 `1,000ms` 미만인 NPC는 랭킹에서 제외합니다. 정확히 1초 이상인 NPC부터 등장하고, 1초 이상 공부한 기록은 퇴장 뒤에도 남습니다.
- **실제 이용자 랭킹**: 표시 기준을 변경하지 않았습니다.

## 보존 사항

- 세 대학 총 144명, 학교별 48명 명단
- 학교별 동시 최대 16명 / 세 대학 최대 48명
- 개인별 일정·가상 공부 시간은 서버에서 생성
- 기존 동적 좌석 및 실사용자 좌석 우선 정책
- NPC 라벨 이름·시간 표시, 가까운 일부만 표시
- 실제 사용자 로그인, 기록, 랭킹, 친구, 채팅, 튜토리얼
