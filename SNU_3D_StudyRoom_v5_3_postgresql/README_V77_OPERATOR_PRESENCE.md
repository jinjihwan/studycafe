# V7.7 - 합산 학습자 인원과 운영자 전용 분리 조회

## 일반 이용자 화면
- `접속 N명 · 가상 M명` 텍스트를 `학습자 (N+M)명`으로 단순화합니다.
- 이 합계는 실제 네트워크 접속자 수가 아니며, Google 계정 팝업에 가상 학습자 포함 안내를 명시합니다.
- NPC 144명 일정, 좌석, 랭킹, 공부 시간, 캐릭터 모델은 변경하지 않습니다.

## 운영자 전용
- 기존 Google 로그인 후 우상단 계정 버튼을 누르면 운영자만 `실제 N명 · 가상 M명 · 합계 X명` 항목을 볼 수 있습니다.
- 서버가 인증된 계정의 친구 코드와 환경변수 `STUDYROOM_OPERATOR_FRIEND_CODE`를 비교합니다.
- 비로그인·다른 계정은 운영자 항목을 볼 수 없고 HTTP 조회도 거절됩니다.
- 계정의 친구 코드는 비밀번호가 아닙니다. 반드시 로그인된 본인 계정과 서버의 일치 여부가 모두 필요합니다.
- 일반 이용자는 여전히 네트워크 개발 도구에서 NPC 동기화 데이터를 확인할 수 있습니다. 정보의 암호학적 은닉이 아니라, **운영자 전용 UI**입니다.

## 설정 방법 (Railway)
1. 출시 주소에서 본인의 Google 계정으로 로그인합니다.
2. 하단 `친구` 탭에서 `ST-`로 시작하는 본인의 친구 코드를 확인합니다.
3. Railway의 웹 서비스 **Variables**에 `STUDYROOM_OPERATOR_FRIEND_CODE=ST-XXXXXXXXXX`를 추가합니다 (실제 본인 코드로 교체).
4. 수정된 환경변수로 배포하고, 본인의 계정에서 우상단 계정 버튼을 열면 상세 인원을 확인할 수 있습니다.
5. 다른 Google 계정이나 게스트로 열면 상세 항목이 나오지 않아야 합니다.

## 코드 경계
- `server/operator-access.js`: 접근 조건 및 권한 검증
- `server/index.js`: `/api/operator/access` GET 라우트 연결
- `index.html`: 합산 학습자 수와 운영자 전용 패널
- `tests/v77-operator-counts.test.js`: 권한·화면·입력 경계 자동 테스트

정적 화면은 권한을 판단하지 않습니다. 운영자 권한은 서버가 확인합니다.
