# V7.0 — 대학 벽면·이용 안내·가상 학습자 일정

기준: V6.9 코드에 최소한의 UI 및 서버 동기화 변경 적용. 로그인, 실제 공부 시간 기록 및 계정 DB 구조는 변경하지 않았습니다.

## 우상단 이용 안내

- 기존 초대/계정 아이콘 사이 `?` 안내 버튼 추가
- 간단한 이용 메시지와 서비스 비공식/가상 학습자 고지
- YouTube 가이드와 Instagram 공지 버튼은 현재 **비활성**
- 링크 확보 후 `index.html`의 `GUIDE_LINKS` 오브젝트에 https URL을 입력하면 활성화됨
- 기존 인터랙티브 튜토리얼은 변경하지 않음

## 대학 뒤쪽 벽면

- 서울대: 앞쪽 끝 벽면을 흰색으로 변경, 사용자 요청 문구를 배치
- 고려대: "너의 젊음을 고대에 걸어라 / 고대는 너에게 세계를 걸겠다"
- 연세대: "진리가 너희를 자유케 하리라"
- **정식 교표는 포함하지 않음**: 대신 캔버스 텍스처 기반 이니셜 플라크를 사용. 정식 교표는 대학별 상표/UI 사용 허가를 받은 뒤 교체 필요.
- 고려대·서울대 요청 문구는 공식 교훈으로 표기하지 않음. 서울대 공식 교훈 "진리는 나의 빛", 고려대의 "자유·정의·진리"와 구분함.

## 가상 학습자 일정

- 대학별 8명까지 생성 가능한 고유한 닉네임 (총 24명)
- **가상 학습자는 사람처럼 속여서 표시하지 않음.** 닉네임 앞 "NPC ·"는 제거하되, 이용 안내와 실제 접속/가상 수 구분, 랭킹 배지를 통해 가상임을 고지
- 시간대별 출현 확률 (한국시간):
  - 00~04시: 1.5%
  - 05~06시: 8%
  - 07~08시: 27%
  - 09~11시: 55%
  - 12~13시: 40%
  - 14~17시: 66%
  - 18~21시: 73%
  - 22시: 48%
  - 23시: 16%
- 30분 슬롯 단위; 날짜·대학·캐릭터·슬롯을 해시해 서버 재시작 후에도 같은 출석 상태 재현
- 공부 시간은 한국시간 자정부터 **0**으로 시작, 출석 슬롯당 시간의 76%만 기록. 날짜 이전 기록을 더하지 않음
- 비활성 시 캐릭터·말풍선이 사라지고 해당 좌석이 비어 있으면 사람이 사용할 수 있음. 실제 사용자 좌석과 겹치면 가상 학습자는 비활성 처리
- 하루 가상 학습자 시간은 실제 계정의 공부 기록 DB에 쓰지 않음. 랭킹 조회 API에서만 계산해 가상 참여자임을 표시함
- 기존 오버플로 방에는 가상 학습자 없음

## 제한 및 후속 작업

- 대학 정식 심벌은 허가 후 사용
- 유튜브/인스타그램 링크는 아직 없음
- 실 PostgreSQL/Google/Railway·실제 모바일 3D 성능/시각 검증 필요
- 이용자 수 지표는 `실제 x · 가상 y`로 구분되며 실제 접속자 통계를 부풀리지 않음

## 적용 방식

GitHub 저장소 최상위에 V7.0 스마트폰 패치 ZIP을 업로드하고 기존 Codespaces에서 압축 해제, `npm run check`, `FORCE_COLOR=0 npm test` 후 커밋합니다.
