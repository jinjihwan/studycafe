# V7.5 — Avatar-centered camera orbit

V7.4의 NPC 좌석 보호, 공부 시간, 랭킹과 사용자 인터페이스는 유지하면서 카메라 회전축만 수정합니다.

## 변경점
- OrbitControls 회전 중심을 캐릭터 앞의 지점 대신 몸통 중심(기준 높이 1.25)에 설정합니다.
- 걷거나 좌석에 앉을 때 캐릭터의 실제 위치와 크기를 기준으로 중심점을 갱신합니다.
- 따라가기에서 회전 목표만 늦게 쫓아가는 지연을 제거합니다. 카메라의 이동량을 동일하게 적용해 현재 회전 각도와 줌을 보존합니다.
- 모바일과 PC 초기 카메라 위치를 바꿔 이전과 유사한 거리를 유지하도록 했습니다.
- 카메라의 회전/확대 축소 UI, 안전 범위, 다른 기능은 변경하지 않습니다.

## 수동 확인
1. 모바일에서 캐릭터가 서 있을 때 카메라를 좌우로 회전해 몸통 주변을 도는지 확인합니다.
2. 바닥 터치 이동 중 카메라 따라가기가 끊기지 않는지 확인합니다.
3. 의자에 앉은 뒤에도 회전 중심이 몸에 붙어 있는지 확인합니다.
4. 핀치 확대/축소와 PC 드래그·휠을 확인합니다.
5. 벽 근처에서는 기존 카메라 안전 범위에 의해 시점이 제한될 수 있습니다.
