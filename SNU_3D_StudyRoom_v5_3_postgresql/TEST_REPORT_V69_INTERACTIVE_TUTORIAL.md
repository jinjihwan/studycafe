## 건너뛴 테스트와 미검증
- 실제 PostgreSQL 연동 테스트는 독립 실험 데이터베이스 접근 자격이 없어 건너뜀
- 실기기 제스처, Google 로그인 팝업, Railway 운영 배포, 다양한 실제 좌석의 서버 승인 및 네트워크 품질에 따른 재접속은 미검증
- 서버의 '백그라운드 탭에서도 소켓이 살아 있으면 공부 시간 진행' 정책은 이번 버전에서 변경하지 않음
