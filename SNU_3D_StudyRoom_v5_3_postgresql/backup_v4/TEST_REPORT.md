# v4 안정성 및 통합 테스트 보고서

## 보존·변경 범위

- v3의 `index.html` Three.js 장면·책상·의자·NPC·동물 아바타·카메라·길찾기·UI를 유지했으며, 추가 변경은 기록/랭킹 탭의 마크업·스타일·자바스크립트 모듈 연결입니다.
- `server/room.js`의 좌석 검증·이동·채팅·Origin/WebSocket 방어를 유지했습니다. 공부 시간 누적은 별도 DB 저장 체크포인트를 사용하도록 조정했습니다.
- 변경 전 v3 코드: `backup_v3/`. 이전 원본 백업: `backup_v1/`, `backup_v2/`.
- 기본 DB: SQLite (`node:sqlite`, Node.js 22.13+). PostgreSQL용 스키마/어댑터는 구현했으나, 실제 관리형 PostgreSQL 접속 테스트는 미실시.

## 실제 실행 요약

- Node.js v22.16.0 환경에서 `npm run check` 통과.
- `npm test`: **11개 테스트 / 11개 통과 / 0개 실패 / 0개 취소**.
- 자동 WebSocket/HTTP 및 실제 파일 재열기/Node 서버 재시작 테스트를 실행했습니다.
- Chromium headless WebGL 렌더링도 시도했으나 이 컨테이너에서 EGL/GPU 초기화에 실패하여 페이지 표시 결과를 판정할 수 없었습니다. 이는 앱에서 발생한 렌더링 오류가 확인되었다는 뜻은 아닙니다.

## 아직 검증하지 못한 항목

- 실제 **스마트폰 또는 PC의 WebGL 화면 렌더링**, 3D 가구 위치/캐릭터 터치 조작, 탭 전환 UX를 최종 기기에서 확인하지 못했습니다.
- 실제 **관리형 PostgreSQL 연결/마이그레이션/재연결**, 네트워크 장애 및 분산 환경은 테스트하지 않았습니다.
- **하드 크래시, 저장소 손상/디스크 부족, 장시간 부하/발열**, 타이머의 수일 연속 운영은 실시하지 않았습니다. 하드 크래시 시 마지막 체크포인트 이후 최대 약 5초의 시간 손실 위험이 있습니다.
- 브라우저 데이터를 삭제하거나 1년 이상 접속하지 않아 게스트 토큰이 만료되었을 때 계정 복구 기능은 **구현되지 않았습니다**.
- 2개 이상의 Node 서버 인스턴스에서 같은 방의 좌석/시간을 공유하는 기능은 **구현되지 않았습니다**.
