# SNU Library Inspired 3D Study Room — 1단계 데모

서울대학교 중앙도서관 열람실 사진과 콘셉트 디자인을 참고한 **비공식 브라우저 3D 데모**입니다.

## 실행 방법

`index.html`은 HTML/CSS/JavaScript 코드가 하나로 들어 있는 파일입니다. Three.js 및 OrbitControls는 **jsDelivr CDN**에서 가져오므로 최초 실행 시 인터넷 연결이 필요합니다. 일부 브라우저는 `file://`에서 ES 모듈을 차단하므로 **로컬 웹서버**에서 실행해야 합니다.

1. ZIP 파일의 압축을 풉니다.
2. 압축을 푼 폴더에서 터미널을 실행합니다.
3. 다음 명령어로 로컬 웹서버를 실행합니다.

   ```sh
   python -m http.server 8000
   ```

4. PC 브라우저에서 `http://localhost:8000` 을 엽니다.
5. 모바일에서는 PC와 같은 Wi-Fi에 접속한 뒤 PC의 내부 IP와 포트를 사용합니다. 예: `http://192.168.0.10:8000` (로컬 네트워크 방화벽 규칙에 따라 접근이 제한될 수 있음).

Visual Studio Code의 Live Server 확장을 사용해도 됩니다. 실제 운영 배포 시에는 정적 호스팅 HTTPS 환경을 이용하세요.

## 조작

- PC: 드래그하여 카메라 회전, 휠 줌, 바닥 클릭 이동, 의자 클릭 착석, WASD/방향키 이동, Shift 빠른 이동
- 모바일: 한 손가락 드래그 회전, 한 번 탭 이동/착석, 두 손가락 핀치 줌
- 왼쪽 상단: 도서관 위치를 표시하는 정보 / 오른쪽 상단: 카메라 따라가기, 캐릭터 편집, 도움말
- 하단: 오늘 누적 공부시간, 일시정지/재개, 좌석에서 일어나기, 테스트용 로컬 채팅

## 구현 범위

- 실제 Three.js 메쉬: 카펫, 반복 책상(88개), 좌석(352개), 사무용 의자 등받이·팔걸이·바퀴, 책상 램프, LED 조명, 양쪽 창문, 구조용 철골 트러스, 벽면 책장·책, 천장
- 반복되는 가구는 `InstancedMesh`로 그리기 호출 수를 줄임
- 격자 기반 A* 길찾기: 책상, 의자, 열람실 외곽을 장애물로 간주
- 직접 제작한 4종 로우폴리 동물: 토끼, 곰, 고양이, 강아지 / 후드티·후드 색상 변경
- NPC 8명: 앉아 공부, 가끔 로컬 채팅, 가끔 일어나 휴식 후 복귀
- 캐릭터 상단 HTML UI: 닉네임, 시간, 5초 말풍선, NPC 구분 표시
- 사용자 공부시간은 브라우저 `localStorage`에 오늘 날짜 기준으로 저장

## 현재 한계 및 주의

- **멀티플레이어 서버, 계정, 친구 초대, 커뮤니티는 아직 없습니다.** '나 1명 · NPC 8명'이 실제 온라인 사용자 수가 아닙니다.
- 원본 건물의 정밀한 실측 자료나 CAD 모델 없이 사진을 참고한 **절차적 근사 모델**입니다. 정확한 건물 디지털 트윈이 아닙니다.
- 의자/책상 길찾기는 격자 장애물 기반으로, 물리엔진 기반 충돌 및 고급 군중 회피가 아닙니다.
- NPC 공부시간과 움직임은 데모 시뮬레이션입니다.
- 공부시간은 서버에 저장되지 않으므로 브라우저 데이터 삭제 시 사라지고 다른 기기와 동기화되지 않습니다. 탭을 비활성화하면 과다 측정을 피하기 위해 자동으로 일시정지합니다.
- Three.js CDN이 차단되면 장면이 실행되지 않습니다. 운영 버전은 라이브러리 로컬 번들링 및 실제 기기별 성능 시험을 권장합니다.
- 이 프로젝트는 서울대학교와 공식 제휴하거나 승인된 서비스가 아닙니다.

## 수정 가이드

`index.html` 모듈 스크립트를 기능별 섹션으로 나누었습니다.

- `CONFIG`: 공간 및 책상 배치, NPC 수, 길찾기 격자 간격
- `buildRoom`: 천장, 창문, 철골, 서가
- `addTable`, `addChair`: 가구와 좌석 생성
- `Navigator`: 충돌 영역과 A* 경로 탐색
- `animalModel`, `Character`: 로우폴리 동물 캐릭터, 애니메이션, 채팅 라벨
- `updateNpcBehaviors`: NPC 데모 상태 전이
- `frame`: 애니메이션 및 HTML 라벨 갱신

보다 큰 서비스로 확대할 때 이 섹션을 ES modules로 분리하고, 좌석 상태 및 시간 저장을 서버 API와 연결할 수 있습니다.
